# Systems Lab

A long-term hands-on journey into system design, systems programming, and computer systems.

The goal is not interview preparation or memorizing system-design patterns.

The goal is to develop deep technical understanding through:

* Learning fundamentals
* Writing real Java code
* Building small systems
* Running experiments
* Benchmarking
* Debugging
* Breaking systems intentionally
* Studying real-world architectures
* Reading influential research papers
* Revisiting concepts through active recall

## Learning Loop

```text
UNDERSTAND
    ↓
IMPLEMENT
    ↓
EXPERIMENT
    ↓
MEASURE
    ↓
BREAK
    ↓
DEBUG
    ↓
EXPLAIN
    ↓
REVISIT
```

## Philosophy

The objective is not to know the most technologies.

The objective is to understand systems deeply enough to:

* Explain how they work
* Implement simplified versions
* Use real technologies correctly
* Measure their behavior
* Debug failures
* Reason about trade-offs
* Design systems from first principles

This repository records that journey.
